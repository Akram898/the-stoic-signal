## 4. Recommended channel settings (2026 Shorts growth)

### Customization → Layout
- **Trailer for people who haven’t subscribed:** upload a 20–40s best Short or a “what this channel is” cut later  
- **Featured video for subscribers:** leave off at launch, or pin latest Short  
- **Featured sections:** “Popular uploads”, “Shorts”, “Uploads”

### Customization → Home tab (after a few videos)
- Shelf: **Shorts**  
- Shelf: **Uploads**  
- Optional: “Start here” playlist

### Channel → Settings (gear)
| Setting | Recommendation |
|---------|----------------|
| **Privacy → Keep all my subscriptions private** | On (personal preference) |
| **Uploads → Publish to subscriptions feed** | On |
| **Advanced → Allow embedding** | On |
| **Advanced → Interest-based ads** | On (for monetization path) |
| **Upload defaults → Visibility** | Public (or Unlisted if batch-scheduling) |
| **Upload defaults → Category** | Education |
| **Upload defaults → Language** | English |
| **Upload defaults → Title/desc language** | English |
| **Comments** | On · Hold potentially inappropriate for review (optional) |
| **Automatic chapters** | On (helps long-form later) |
| **Featured places / shopping** | Off until needed |
| **Made for kids** | **No** (critical — wrong setting kills growth/monetization) |
| **Paid promotion** | Off unless required |

### Studio → Settings → Channel → Feature eligibility
- Aim for: **1,000 subs + 10M Shorts views / 90 days** (or 4,000 watch hours long-form path)  
- Turn on **YouTube Partner Program** only when eligible

### Notifications
- **Email** for comments + copyright (on)  
- Mobile app: enable push for comments first week

## 7. Growth settings that actually move the needle

Do these; ignore the rest at launch:

1. **Hook in first 1–2 seconds** every video (you already design for this).  
2. **Consistent face/brand** (MARCUS every open/close) — algorithm + humans remember you.  
3. **Daily Shorts** > perfect weekly.  
4. **Reply to every comment** first 48h (signals community).  
5. **Watch Analytics:** “Viewed vs swiped away” — if &lt;70%, rewrite hooks, not thumbnails.  
6. **Never** spam 5 Shorts in one hour on day 1 — post 1/day.  
7. After 10–15 Shorts: first **long-form 6–8 min** to build watch hours + authority.  
8. Avoid pure quote-slideshow AI slop; your motion + POV is the moat (YouTube inauthentic-content risk).
